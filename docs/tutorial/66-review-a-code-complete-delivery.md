## 为什么这么做

### 一、先判「能不能覆盖」，再谈「好不好」

这是第三份要求「更好就覆盖」的外部交付。前两次的教训（第 62、63 章）是
**先建可比的对照**。这次更省事，因为有一个更快的判据：

> **扫它的 overlay 里有没有我们这边独有的修正痕迹。**

逐项 grep：`source_prefix` / `ProviderNotRegistered` / `throttle` /
`QUALITY_POLICIES` —— **出现在 0 个文件**。

结论立刻清楚：它的基线是**它自己的 P3-3**，不是我们的。覆盖等于把
P3-0…P3-3 的十几处修正静默回退。⇒ 只合它**新加的那一层**（P3-11…P3-17）。

> 通用原则：判断一份外部交付能不能整份接受，不要读它的 diff ——
> **去数它包不包含你这边已知的修正**。包不住就只能按层合。

值得说的是它的自述很准：`code_acceptance: PASS` / `live_acceptance: NOT RUN`，
并明确写着哪些证据「只能在真实环境产生，不伪装成已完成」。
**这个边界划得对**，比前两份诚实。

### 二、改掉的五处，是同一个形状

| # | 它怎么写的 | 坏起来什么样 |
|---|---|---|
| 1 | `code_ready = not [e for e in errors if not e.startswith("five consecutive") …]` | 两类错误堆一个 list，再用**错误文案的前缀**捞回来分类 |
| 2 | 硬编码 7 条 `provider → 模块路径` map | 注册了但不在 map 里的**一个都不查**，却打印「registered provider modules exist」 |
| 3 | 手写一张平行的 `PROVIDER_BINDINGS` | 与 `DatasetDefinition` 三个字段是**孪生清单** |
| 4 | `datetime.now(timezone.utc)` 写验收账本 | 差 8 小时**但仍是个合法时刻** |
| 5 | `status.startswith("FAILED")` | 按字符串形状分类 |

> 🔴 **五条都是「判据挂在了会漂的东西上」**：挂在文案、挂在一张手写清单、
> 挂在另一份同源数据、挂在时区默认值、挂在字符串前缀。
> 它们今天都**碰巧对**，而它们错的那天**都不会报错**。

第 1 条最值得看：`code_ready` 靠 `e.startswith("five consecutive")` 把上线面的
错误排除掉。今天对，是因为两类错误的文案恰好互不重叠。改一句措辞，
`code_ready` 就悄悄翻面，**而不会有任何测试红**。

改法不是「把前缀列全」，是**从头就两个 list**。

### 三、三处 deploy 面没合，根因同一个

1. `WorkingDirectory=%h/easyup-biga` —— 路径不存在，装上起不来
2. `ExecStart=… python -m …` —— 本机只有 `python3`
3. 单元名 `biga-eod-daily-bars`（`biga-` **前缀**）而非 `-biga` 后缀

> 三条合起来说明一件事：**这套 deploy 面从没在这个环境里跑过。**

第 3 条最危险，因为它**最安静**。`isolation.py` 的判据是「引用 BigA 路径的
单元名以 `-biga.*` 结尾」。前缀式的名字它根本不把它算成 BigA 的单元，
于是一声不吭地放行。

> 🔴 **比报红更糟。** 报红会被修；静默漏检不会 —— 没人知道要去修什么。

## 坑

### 坑 1 · 一条测试过的是另一道检查

给回放的「哈希漂移必须拒绝」写探针：短路掉 manifest 那条检查，
期待测试变红。**它没红。**

原因：`_verify_legacy_raw()` 里有**两道**哈希检查 —— raw 行自存的 sha、
manifest 记的 sha。我的用例改了正文，两道都会触发，所以关掉一道，
另一道接住了。

那条测试是真的，但它**证明的不是它声称的那件事**。

更要紧的是：manifest v1 的老条目只有 `snapshot_id`、没有 `content_sha256` ——
那些证据集的完整性**全靠 raw 行自存的 sha**。不单独钉住它，把它删掉时
没有任何测试会红，而线上那批老证据集从此裸奔。

⇒ 补一条构造出「只有一道能生效」的场景（manifest 去掉 sha + 正文漂移）。

> 通用原则：**两道检查互为冗余时，一条用例证明不了任何一道。**
> 要么各自构造只有它能触发的场景，要么承认其中一道没有守卫。

### 坑 2 · 探针指向一个不存在的测试文件

另一条探针「破坏后红 / 还原后**仍红**」—— 因为目标测试文件我压根没写。
pytest 对不存在的路径两次都非零退出，看起来像「一直红」。

> 判据是 `破坏后红 **且** 还原后绿`。缺了后半句，「一直红」会被读成「红了」。
